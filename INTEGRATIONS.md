# Проверка интеграций — 05.11.2026

## FatSecret

Доступ к существующему личному дневнику описан официально: трёхсторонний OAuth 1.0 связывает разрешение с существующим аккаунтом fatsecret.com. Это отдельный механизм от доступа к базе продуктов и от создания нового профиля API. [Официальная схема авторизации](https://platform.fatsecret.com/docs/guides/authentication/oauth1/three-legged).

Метод `food_entries.get.v2` возвращает записи на выбранную дату; дата передаётся числом дней от 01.01.1970. В ответах есть калории, белки, жиры и углеводы отдельных записей. Для будущего импорта надо получать суточный итог с заменой, а не прибавлением повторного ответа. Требуется отдельно согласовать долговременное хранение показателей: документация перечисляет ограничения на сохраняемые значения. [Метод и структура ответа](https://platform.fatsecret.com/docs/v2/food_entries.get).

На странице тарифов указаны Basic: бесплатно, 5000 вызовов в день, данные США, обязательная атрибуция; Premier Free требует проверки соответствия условиям, Premier для бизнеса рассчитывается по запросу. Эти условия сами по себе не доказывают доступ конкретного зарегистрированного приложения к личному дневнику. [Тарифы](https://platform.fatsecret.com/api-editions). Для доступа требуется [регистрация приложения](https://platform.fatsecret.com/register) и фактическое прохождение OAuth пользователем.

Итог: технический путь к существующему дневнику документирован. Реальная авторизация, доступность для региона пользователя, разрешения ключа, квоты и условия хранения не проверены: приложения FatSecret и его ключей в этой сессии нет. Автоматический импорт не реализован и не показывается работающим. Первая версия полностью использует ручной ввод.

## HONOR Здоровье

На официальном портале HONOR есть Fitness/Health Kit SDK с Android-координатой `com.hihonor.mcs:fitness-health:1.0.0.302`. [Страница SDK](https://developer.honor.com/cn/kitdoc?category=&docId=&kitId=11005&navigation=sdk&token=).

В официальном перечне передачи данных упоминаются приложения, интегрировавшие Health Kit, пользовательское разрешение и передача через интерфейсы устройства/сервера. Это подтверждает существование партнёрских механизмов, но не общедоступный браузерный API для данной PWA. Документ относится к указанному в ссылке региону; распространять его условия на все аккаунты нельзя. [Официальный перечень](https://agreement.itsec.honor.com/asm/agrFile/getHtmlFile?agrNo=1213&branchId=11&country=cn&langCode=en-us).

Итог: подтверждённый маршрут получения шагов и тренировок именно из HONOR Здоровье на HONOR 200 Pro / Android 16 в чистой PWA не установлен. Это не утверждение о технической невозможности. Перед реализацией нужны версия и регион HONOR Здоровье, доступ разработчика к документации/разрешениям и проверка на физическом телефоне. Health Connect, Huawei Health и другие сервисы вместо HONOR не подключаются: подтверждённой цепочки передачи данных для устройства пользователя нет. Интеграция не реализована.

## Правило будущего подключения

Только после проверки на реальном аккаунте: отдельное согласие, шифрованное хранение токенов на сервере, идентификатор источника + дата + тип показателя, идемпотентная замена суточного итога, время импорта. Ручные изменения требуют разрешения на замену; отключение сервиса сохраняет ранее импортированную историю. Ни один этот статус не имитируется в текущем интерфейсе.
